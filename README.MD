# padluppcore

Production source: `padlupp/main` at `https://github.com/padlup001/padluppcore.git`.
The `origin` remote remains a synchronized secondary copy.

Main-branch pushes to the canonical repository run tests and automatically deploy
through the protected production environment. See
[automatic deployment operations](deployment/automatic/README.md) for verified
backups, migration restrictions, immutable releases and data-preserving rollback.
Marketing and mobile deployment are not enabled by this setup.
